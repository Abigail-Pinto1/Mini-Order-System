Mini Order Processing System (TypeScript)
Project Overview

This project is a Mini Order Processing System built with TypeScript. The system simulates how a small online store processes customer orders. It demonstrates core TypeScript concepts such as interfaces, typed functions, array methods, business logic enforcement, and error handling.

All data is stored in memory and no database is used.

Technologies Used

TypeScript
Node.js
npm

How to Run the Project
1. Install Node.js

Download and install Node.js:

https://nodejs.org

Verify installation:

node -v
npm -v
2. Install Dependencies

Inside the project folder run:

npm install
3. Compile TypeScript
npm run build

This compiles TypeScript files into JavaScript inside the dist folder.

4. Run the Program
npm start

This runs the compiled program using Node.js.
